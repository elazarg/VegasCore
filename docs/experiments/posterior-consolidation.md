# Qualified-binding posterior consolidation

Decision: retain the existing full-law probability interface and accept its
checked local simplification. Reject forcing the new power/tensor interface
into this consumer. The experiment is retained on
experiment/consolidation-posterior.

The actual owner is
[StoppedPayoff](../../Vegas/Game/QualifiedBinding/StoppedPayoff.lean), including
its `annotated_admitted_tape` payoff consumer. The posterior declaration changes
from 129 to 109 physical lines and its proof from 82 to 62. The entire owning
module loses 20 lines. There are no additional helpers, adapters, fixtures or
hypotheses. Explicit reduction of the local block and rank expressions allows
both observations to use the same Option match and the stronger posterior-map
identity directly.

The result still gives equality after any PMF-valued continuation kernel on any
outcome type. All original profiles, tape observations, support and positivity
conditions remain. In particular, the atom identities used by the actual
annotated-likelihood consumer are retained. The complete source owner passed
the strict check and its normal build.

The tensor API proves selected conditional expectations. To recover this
consumer's complete law, it would need a separating family of atom indicators
or an equivalent complete span, plus the actual source/native callback and
transcript correspondence. The issued completed foreign word is not itself
the sequence of observations possessed while that word was produced. Recording
every protocol transition would introduce additional idle/clock information;
recording only callbacks requires a proved skip-to-callback kernel and recall
correspondence. No such adapter or smaller closed family is supplied by the
consumer's arbitrary-profile hypotheses. Its existing restricted-disintegration
owner already proves the full conditioned pair and atom laws directly.

Power completeness preserves a limiting assessment. It does not identify the
original stagewise profiles, pooled weights, operational rate hierarchy or
quantitative posterior-error bounds. Replacing those original sequences with
powers would require a new global sequence construction and renewed comparison
proofs. That is not a local compression of the existing arbitrary-sequence
theorems.

No native tensor table, callback/transcript adapter, closure dimension or
numerical saving for such a construction is claimed. The rejection is scoped
to this full-law consumer; it does not refute a future selected-gain certificate
with a justified sufficient observable family. The accepted saving is a
20-line proof simplification using the existing stronger API, not a measured
runtime adoption of the new certificate machinery.
