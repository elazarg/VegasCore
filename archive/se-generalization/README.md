# SE generalization reference archive

This directory is reference material, not an active implementation or proof.
No archive directory belongs to a Lake library or default build root.

- Lean sources retain their original paths beneath lean, with a final .txt
  suffix. They cannot supply imported Lean modules and are not compiled.
- Documents and investigations are beneath documents. Markdown snapshots also
  have a final .txt suffix, so they are not active documentation or proof citations.
- Finite Python probes remain reference tools. Their action spaces, timing,
  penalties and equilibrium quantifiers must match a proposed experiment; a
  failed prescribed strategy is not a preservation impossibility result.
- [manifest.csv](manifest.csv) records each original path, archived path, reason
  and SHA-256 digest. Contents are preserved exactly, including unfinished drafts.

The [schedule analysis snapshot](documents/docs/se-schedule-generalization.md.txt)
contains the detailed proof investigations and protocol alternatives. The
[active design and plan](../../docs/se-schedule-generalization.md) is authoritative.
Search this archive before reinventing a helper, but check its model, quantifiers
and unproved premises before restoring it to the active tree. Archived status
claims do not establish the active preservation theorem.
